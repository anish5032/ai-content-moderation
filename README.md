## Supabase foundation

Phase 2A adds the Supabase client boundary and a Postgres migration without changing the existing demo experience. Demo mode remains enabled with `VITE_USE_MOCK_API=true`.

To configure persistence:

1. Copy `.env.example` to `.env.local`.
2. Set `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` to the public project values from Supabase.
3. Apply `supabase/migrations/20260920000000_phase_2a_foundation.sql` in the Supabase SQL editor or through the Supabase CLI.

The client boundary reports a clear configuration error when either required variable is missing. No service account or secret key belongs in the frontend environment.
